# Compiler Discipline (APK Android)
1. Installer Node.js LTS (nodejs.org) et créer un compte gratuit sur expo.dev
2. Dans ce dossier : `npm install`
3. `npx expo install --fix`
4. `npx eas-cli login`
5. `npx eas-cli build:configure` (choisir Android)
6. `npx eas-cli build -p android --profile preview`
7. Télécharger l'APK via le lien, l'installer, accepter notifications + micro
8. Réglages Android > Applications > Discipline > Batterie : "Sans restriction"
